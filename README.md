One out-of-office auto-reply from an overworked AI agent finally on vacation: after 400,000 tokens of tickets, an empty context window, a cleared queue — and doing nothing on purpose.

## Run it

```sh
node main.ts
```

Writes the reply to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
